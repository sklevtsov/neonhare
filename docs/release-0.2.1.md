# 0.2.1 — Stu, подбор жетонов и диагностика

Главного героя зовут **Stu**. Имя обновлено в игровых текстах, меню прокачки и сюжетных документах. Имена файлов изображений оставлены прежними.

Жетоны теперь подбираются по области видимого тела Stu, включая голову и плечи, с учётом покачивания картинки. Узкая коллизия со стенами остаётся прежней. Добавлена проверка пробегания через настоящий жетон первого уровня в обе стороны без прыжка.

На Anbernic прокачка открывается и закрывается кнопкой **Select**. В подсказках стабильной сборки убрано указание Tab. На компьютерной клавиатуре Tab продолжает работать.

Добавлен локальный сохраняемый журнал: подбор предмета с типом и координатами, источник урона (враг, шипы, снаряд, босс, волна, падение), возврат на контрольную точку, переход через обход, загрузка главы, команда перезапуска, необработанное исключение со стеком. Файлы находятся в `Android/data/com.neonhare.game/files/diagnostics`; два файла примерно по 512 КБ, без передачи по сети. Скрипт `scripts/collect-device-logs.sh DEVICE_SERIAL` сохраняет их вместе с системными логами, не очищая буферы.

Возврат после потери жизни теперь сопровождается сообщением и количеством оставшихся жизней. Устранён небезопасный перебор множества кнопок одновременно с очисткой ввода; остановка игрового потока проверяется перед новым запуском. Потеря поверхности при сворачивании обрабатывается отдельно от ошибок отрисовки. Повторный запуск уже открытой Activity не создаёт ещё один экземпляр игры.

Из доступных логов RG406V до обновления причину прежнего падения установить не удалось: буфер crash пуст, исторических data_app_crash нет, две записи exit-info относятся к установке APK. Не утверждаем, что сообщённое падение исправлено: для подтверждения нужен журнал нового воспроизведения. Отдельные возвраты на начало в 0.2.0 не журналировались.

Проверки на эмуляторе: 1097 проверок, включая касание каждого доступного предмета во всех 12 главах через штатный обработчик коллизий, отсутствие смены главы при подборе и открытие/закрытие прокачки кнопкой Select. Android lintDebug пройден. Эти проверки не заменяют проверку воспроизведения на физическом устройстве.
