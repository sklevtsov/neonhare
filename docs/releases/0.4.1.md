# Neon Hare 0.4.1 — Stu's barrel, public project foundation

## English

- Projectiles and muzzle effects now originate at the visible barrel in standing, all eight running frames and helicopter flight; facing left mirrors the same attachment.
- Projectile collision bounds now match their drawn centre. A barrel beside a solid wall cannot spawn a shot beyond it.
- Bilingual repository presentation with real gameplay captures and a new promotional wordmark.
- Independent chapter authoring, gameplay/save regressions and explicit signing remain the development foundation.
- Game text is currently Russian; English localisation is planned. Twelve existing chapters remain prototypes under balance/tutorial refinement.

**Release checklist:** add the actual signed APK certificate SHA-256 and Anbernic/Samsung validation results here before publishing. The release workflow creates a draft; this note does not certify a public release or device validation. Existing local-development APKs may have another signing identity: arrange save migration before any uninstall.

## По-русски

- Пули и эффект выстрела выходят из видимого дула: стоя, во всех восьми кадрах бега и при полёте. Поворот влево зеркалит общую точку крепления.
- Область попадания соответствует нарисованному центру пули. Длинный ствол возле стены не создаёт выстрел за преградой.
- Подготовлены README на двух языках, настоящие игровые кадры и промо-логотип.
- Сохраняются независимое добавление глав, проверки механик/сохранений и явный процесс подписи.
- Игра пока на русском; английская локализация запланирована. Двенадцать глав остаются прототипами: баланс и обучение дорабатываются.

**До публикации:** указать отпечаток сертификата реальной APK и результаты проверки на Anbernic/Samsung. Workflow создаёт черновик, а не автоматически подтверждённый стабильный выпуск. При отличии подписи старой локальной сборки сначала решить перенос сохранения, а не удалять игру.
